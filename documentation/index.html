HandyPro – Buyer Customization Guide

Overview

This template is built with a clean static HTML/CSS structure. Most edits are done in index.html and style.css. Use this guide to quickly replace the logo, adjust the color palette, and update the business phone numbers.

1) Change the company logo

The header logo is typically located in the top navigation area of index.html. If your theme uses a CSS-generated logo block, replace it with your own image or branded text. 

<!-- Open index.html and edit the brand area -->
<a href="#home" class="brand" aria-label="Your Company home">
  <img src="assets/logo.png" alt="Your Company Logo" width="160" height="52" />
  <span class="brand__text">
    <span class="brand__title">Your Company</span>
    <span class="brand__subtitle">Home Services</span>
  </span>
</a>
If you want to use a custom logo image, upload it to your project folder, for example: assets/logo.png or images/logo.png, then update the src path above.

Also check the footer brand section in the same file, because the logo often appears there too.

<!-- Example: change brand text -->
<span class="brand__title">HandyPro</span>
<span class="brand__subtitle">Home Services</span>

2) Edit the theme colors in CSS

The color palette is controlled from the root variables in style.css. Open the file and update the values in the :root block. 

/* style.css */
:root {
  --color-primary: #f75d1c;
  --color-primary-dark: #d94a10;
  --color-secondary: #0c1e35;
  --color-secondary-strong: #102a46;
  --color-surface: #f5f7fb;
  --color-white: #ffffff;
  --color-text: #243244;
  --color-text-muted: #5e6d80;
}
Primary accent Change --color-primary for buttons, highlights, icons, and hover states.
Dark brand color Change --color-secondary for main headings, header backgrounds, and text blocks.
Backgrounds Update --color-surface and --color-white for card and page tone.
Example: to change the main orange accent to blue:
Replace #f75d1c with your preferred color, such as #1d4ed8.

3) Update the contact phone numbers

Phone numbers are hardcoded in multiple places in index.html. Replace each instance with your business number. 

<!-- Header contact number -->
<span class="header__call-number">+1 (800) 123-4567</span>

<!-- CTA button tel link -->
<a href="tel:+18001234567" class="btn btn--primary">Book a Free Estimate</a>

<!-- Footer contact item -->
<span>+1 (800) 123-4567</span>

Search the file for the old number and replace it with your actual business contact:

+1 (800) 123-4567
tel:+18001234567
Use the same number in both visible text and the tel: link so the phone link works correctly on mobile devices.

Quick checklist

  • Replace the logo in the header and footer.
  • Update company name and subtitle text in index.html.
  • Modify the CSS variables in style.css to match your brand colors.
  • Replace every phone number and tel: link with your real business contact details.
  • Test the website in a browser after edits.
